# Frontend Design Mocks

Static review mocks for Nature Grid visual direction before implementation.

Open `index.html` in a browser to review the proposed theme and layout direction.

## Pages

- `index.html`: public dashboard
- `data.html`: data hub
- `observations.html`: observations explorer
- `reports.html`: citizen reports
- `alerts.html`: disaster and environmental alerts
- `biodiversity.html`: biodiversity records
- `restoration.html`: restoration projects
- `community.html`: community content and campaigns
- `profile.html`: citizen profile
- `admin.html`: admin operations console
- `theme.html`: theme tokens and component states

## Recommendation

Use the `Civic Nature` direction:

- Neutral app surfaces for serious data workflows.
- Deep green primary actions and active navigation.
- Teal/blue accents for maps, water, and environmental data.
- Amber/red only for warnings and disaster severity.
- Compact dashboard layout instead of a marketing-style landing page.

This keeps the environmental identity without making the whole UI one-note green.
