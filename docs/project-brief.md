# Project Brief

## Mission

Nature Grid exists to make environmental information easier to collect, verify, analyze, and act on. It connects citizens, researchers, organizations, and public agencies around shared environmental data, reports, alerts, and biodiversity observations.

## Vision

Nature Grid should become a trusted civic environmental intelligence platform for Bangladesh first, then other regions later. The long-term goal is a platform where local reports, scientific observations, government alerts, and machine-ingested datasets can be viewed together on a reliable geospatial data grid.

## Product Promise

- Public users can understand the platform from one public page without being forced to log in.
- Citizens can report local environmental problems with location and media evidence.
- Researchers can contribute and validate higher-quality observations and datasets.
- Organizations can manage projects, campaigns, and verified environmental work.
- Government/admin users can moderate reports, issue alerts, and manage operational datasets.
- Public users can explore environmental conditions, biodiversity signals, and warnings.

## Public-First Product Shape

The first page at `/` should be a complete public environmental board, not a login wall and not a thin marketing page. It should show public summaries of alerts, verified reports, datasets, observations, biodiversity, restoration, and community campaigns.

Login is required only when the user wants to contribute, download, personalize, or access advanced data workflows.

## First Geographic Focus

Bangladesh.

Initial location hierarchy:

- division
- district
- upazila
- union
- water body
- pollution source

## Core Product Areas

| Area | Purpose |
| --- | --- |
| Public Home | Single-page public board with the project summary and public environmental data |
| Data Hub | Public dataset previews; login-gated advanced filters, downloads, and contribution |
| Observations | Public verified observations; login-gated submission and validation |
| Citizen Reports | Public verified reports; login-gated submission and tracking |
| Alerts | Disaster and environmental warnings with severity and zone data |
| Biodiversity | Species, habitats, sightings, and research-grade records |
| Restoration | Conservation/restoration projects and contribution tracking |
| Community | Campaigns, articles, challenges, and environmental education |
| Admin | Moderation, alert management, dataset operations, organizations, and audit logs |
